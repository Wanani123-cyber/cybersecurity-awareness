# 📋 Daily Cybersecurity Awareness Checklist

### 1. Password & Access Security
- [ ] Enforce Multi-Factor Authentication (MFA) across all corporate and personal accounts.
- [ ] Maintain unique passwords of at least 16 characters using an authorized password manager.
- [ ] Lock workstation screens immediately when stepping away from the device.

### 2. Email & Network Security
- [ ] Inspect sender email addresses carefully for typosquatting or spear-phishing cues.
- [ ] Verify the HTTPS secure padlock icon on web domains before entering credentials.
- [ ] Avoid unencrypted public Wi-Fi networks unless an enterprise VPN is active.

### 3. Data Protection & Hygiene
- [ ] Confirm that full-disk encryption (e.g., BitLocker / FileVault) is enabled.
- [ ] Perform regular automated backups of critical files to secure cloud or offsite storage.
