# 🛡️ Cybersecurity Awareness & Baseline Checklist

## Overview
This repository contains a comprehensive cybersecurity awareness resource and baseline checklist designed for employees, students, and junior analysts to maintain essential digital security hygiene. 

## Project Structure
- `README.md`: Project overview and documentation.
- `checklist.md`: Operational security checklist.
- `cybersecurity_awareness.txt`: Awareness tips and incident reporting notes.

## Usage
Review the checklist periodically to ensure system, account, and operational security controls remain active.
